Training split

Updates model weights. The only data the optimiser sees.

Validation split

Chooses thresholds, epochs, the input variant and the dashboard model. Never updates weights, so its scores are optimistic.

Test split

Touched once, after every choice is frozen. Gives the reported result. The detector test is held for the final project.
